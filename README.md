# Manifold Academy · 流形学堂

从基础微积分出发，通过具体计算、交互实验与分步推导学习理论物理。现代几何是逐步建立起来的语言；起步课程先解释每个工具要解决什么问题。

## 学习路线

| 阶段 | 内容 | 学习目标 |
| --- | --- | --- |
| 微积分桥梁 · 6 节 | 量纲、线性测量、链式法则、行列式、微分方程、复数 | 能识别一个函数、一个方向和一份累计规则 |
| 几何体验 · 6 节 | 圆周图卡、切向量、1-形式、外积、曲线积分、曲面面积 | 先在具体曲线和曲面上完成计算 |
| 物理起点 · 8 节 | 能量、路径变分、相空间、场、概率、旋转、两态量子模型、Maxwell 方程 | 了解各学科研究什么，并算出最小模型 |
| 几何主线 | 流形、切/余切空间、形式、积分、外微分、Stokes、李导数 | 把具体操作组织成严格定义与定理 |
| 理论与应用 | 拉格朗日、哈密顿、李群、电动力学、统计、量子 | 逐步进入几何推广和专题应用 |

首页及“学习路线”提供十门课程的先修关系、目标和出口问题。默认每次阅读一节，支持整章阅读、上/下一节、本机续读及跨课程复习链接。原有七学科专题、作业与实验室继续保留，进阶内容在课前导引中注明。

### 积分专题 1.7

先回答“f 必须是物理密度吗”，再从有限小段的贡献推到积分定义。随后完整计算一维换元、平面曲线、二维参数映射，解释定向与单位分解。一般流形上的严格定义、坐标无关证明、可积性和密度放在可展开的第二遍研读卡片中。

五类随文实验分别展示线性测量、行列式与定向、参数换元、沿曲线求值与累计、重叠图卡的加权分工。每个实验提供控制项、数值结果、解释和重置按钮；积分实验明确区分有限分割误差与精确积分。

## 本地开发与校验

需要 Node.js 24+（校验脚本使用原生模块加载钩子）。

```bash
npm install
npm run dev
npm test
npm run build
```

Windows 可用 `cmd /c "npm run build"`。开发服务器默认位于 `http://localhost:5173/`，生产产物位于 `dist/`。生产包使用相对资源路径，可部署到 GitHub Pages 子目录。

`npm test` 校验课程依赖与锚点、全部课程公式的 KaTeX 解析、五类实验的数学不变量，以及阅读器跳转、续读、折叠目录、实验输入与重置的 DOM 行为。它不替代浏览器中的布局和视觉检查。

## 内容与代码结构

- `src/data/learningPath.js`：学习顺序、先修关系、复习入口与出口问题。
- `src/data/curriculum.js`：学科分类、课程注册及旧章节锚点兼容。
- `src/data/chapters/tutorialChapters.js`：三门起步课程。
- `src/data/chapters/integrationJourney.js`：1.7 的问题、算例与交互主线。
- `src/data/chapters/integrationDefinition.js`：1.7 展开卡片中的严格参考。
- `src/data/chapters/integrationFoundations.js`：测度与勒贝格积分基础。
- `src/labs/lessonLabModels.js`、`lessonLabs.js`：可测试的数学模型与随文 SVG 实验。
- `src/components/chapterViewer.js`：按节阅读、复习跳转与实验生命周期。
- `docs/LEARNING_DESIGN.md`：教学框架、符号引入顺序与扩展原则。

技术栈：Vite、原生 ES 模块、KaTeX、SVG 与 Canvas。课程公式在 JavaScript 字符串内必须正确转义；新增内容遵守 [AGENTS.md](AGENTS.md)。
