# Manifold Academy · 流形学堂

> **以现代微分几何为经纬，以动力学与物理对称性为骨骼**  
> 面向高能物理、加速器束流动力学（Beam Dynamics）与现代场论的交互式理论物理学习平台。

---

## 🌟 核心特色与设计范式

1. **几何化主线贯穿（Coordinate-Free Geometry）**：
   - 告别局部坐标系的繁复微商计算。
   - 深入位形流形切丛 $TQ$（拉格朗日切丛几何与变分极值）、余切丛 $T^*Q$（典范辛 2-形式 $\omega = dq^i \wedge dp_i$、哈密顿相流保辛性与 Liouville 保体积定理）。
   - 麦克斯韦方程在时空流形上的微分形式 $dF = 0, \star d\star F = J$ 与超相对论辐射锥（$1/\gamma$ 集束）。
   - 连续李群李代数对称性（$SO(3)$ 与 $SU(2)$ 的双重覆盖拓扑同伦）。
   - 现代统计力学的相空间粗粒化（Coarse-graining）与微观可逆动力学中的不可逆熵增。
   - 现代几何量子力学（Fubini-Study 度规、Berry 几何相位与相空间 Wigner 拟概率分布）。

2. **加速器束流动力学无缝衔接**：
   - 严格推导 Courant-Snyder 理论与相空间 Twiss 参数 $(\beta, \alpha, \gamma)$。
   - 证明磁铁传输矩阵 $M \in Sp(2, \mathbb{R})$ 作用下单粒子发射度（相椭圆面积 $\pi \epsilon$）的严格守恒。
   - 揭示非辛算法（如经典 Runge-Kutta 4）在长程束流追踪中引发的人工能量耗散与发散，论证辛积分器（Symplectic Integrators）的数学物理不可替代性。

3. **内置高帧率交互式数字实验室（Interactive Digital Labs）**：
   - **哈密顿与束流光学实验室**：辛积分器（Symplectic Euler）vs 经典 4 阶 Runge-Kutta (RK4) 能量漂移比对；四极透镜与自由漂移段在相空间的辛变形与粒子散点追踪。
   - **拉格朗日最小作用量实验室**：鼠标拖拽试探路径，实时数值积分作用量 $S[\gamma]$，一键执行变分流松弛，亲眼见证路径沿 Euler-Lagrange 负梯度收敛至真实物理极值轨道。
   - **统计力学 Baker 变换实验室**：单位相空间中 8,000+ 粒子的保测度拉伸折叠（混沌细丝化），探测器粗粒化网格下的 Gibbs 熵单调攀升至热动平衡极大值。
   - **现代微分几何外形式实验室**：操控切向量 $u, v$，直观呈现外积 $u \wedge v = - v \wedge u$ 的有向平行四边形面积与定向符号。
   - **相对论电动力学实验室**：相对论运动电荷辐射波前模拟，光速挤压与 $1/\gamma$ 同步辐射圆锥。
   - **李群 $SU(2)$ 旋量实验室**：连续旋转三维刚体，体验 $360^\circ$ 复位但费米子旋量变号 $-1$、旋转 $720^\circ (4\pi)$ 才完全同伦复原的拓扑机制。
   - **量子力学波包隧穿实验室**：实时解算 1D 薛定谔波包撞击有限高势垒，透射波与反射波相干干涉。

4. **严谨推导与作业研讨系统（Problem Sets）**：
   - 每章精选研究级与物理建模习题。
   - 配备分步启发式提示（Hints）与完整的逐步数学证明推导（Solutions）。
   - 支持本地 `localStorage` 学习进度与习题打卡。

## 🚀 本地运行指南

项目基于现代极速前端构建工具 **Vite** 与 **KaTeX** 开发，极度轻量，无冗余重型依赖。

### 1. 启动本地开发热更新服务
```bash
npm run dev
```
启动后在浏览器打开：`http://localhost:5173/`

### 2. 构建生产静态包（可直接上传至 GitHub Pages）
```bash
npm run build
```
编译产物位于 `dist/` 目录，单目录纯静态分发，随时可以推送到 GitHub Pages 托管。
