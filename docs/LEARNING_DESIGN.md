# 从基础微积分进入理论物理

## 起点与分层

读者只需掌握一元求导、定积分、三角函数及初等代数。不能把“给出先修名词列表”视为教会这些内容。课程采用三层结构：起步层完成工具与最小模型的计算；严格层给出一般对象、条件和证明；应用层进入束流、规范丛、遍历问题与几何量子化。

这次重构落实了三门共二十节的起步课程，并重写积分的引入路径。原七学科的研究专题继续作为研读层，而不是声称二十节已替代完整的本科线性代数、电磁学、统计力学和量子力学教材。

## 阅读路线与学科分类

`learningPath.js` 是课程学习依赖的来源；`curriculum.js` 是主题分类。两者不可混用。线性路线给出可行的一条学习路径，先修链接体现哪些分支可以独立进入。知识图谱展示概念联系，不能把每一条连线解释成一个定理的逻辑推出。

推荐路线为：微积分工具 → 几何体验 → 物理模型 → 严格微分几何 → 拉格朗日 → 哈密顿 → 李群 → 电动力学 → 统计 → 量子。

保留已有章节编号和锚点，以免旧链接失效。微分几何的第一遍推荐顺序允许先读 1.5 的测量操作与 1.7 的连续函数算例，再回读 1.6 的测度论构造和 1.4 的丛语言。默认按节阅读；参考内容使用原生 `details`，链接定位内部定义时须自动展开祖先卡片。

## 每节内容的最小完整链条

1. 提出一个能用日常量或已有微积分表达的问题。
2. 说明输入是什么、输出是什么、要保持什么不变。
3. 完整计算一个小例子，解释每个新符号。
4. 给出定义、适用条件与记号，而后证明它实现了所需性质。
5. 提供一个能区分相近概念的理解检查，而不是只要求背诵公式。

例子不承担它没有证明的结论。有限个图像不能代替一般定理；有限分段和的近似不变性也不能当作精确换元不变性。物理定律和量子公设明确标为模型输入。

## 积分的概念依赖

| 需要解释的问题 | 先行工具 | 本项目的落实位置 |
| --- | --- | --- |
| 函数值是否就是局部总量？ | 单位、变化率、累计规则 | 0.1 与 1.7 一 |
| dx 到底接受什么？ | 向量与线性函数、链式法则 | 0.2–0.3、G.2–G.3、1.3 |
| 为什么积分形式等于积分系数？ | 有限分割、线性求值、黎曼和 | 1.7 二 |
| 换参数为什么还要乘导数？ | 位置复合与方向映射分别追踪 | 1.7 三与换元实验 |
| 曲线与曲面怎样累计？ | 速度、两个参数方向、行列式 | G.4–G.6、1.7 四–五 |
| 为什么形式变号而质量不变？ | 定向与非负长度是不同数据 | 1.7 六 |
| 多张图为什么需要权重？ | 积分线性与避免重复计数 | 1.7 七与分工实验 |
| 如何处理一般可积对象？ | 可测集合、测度、简单函数 | 1.6 与 1.7 严格参考 |

连续函数在有限区间上的积分不要求函数有“质量密度”意义。要赋予物理总量解释，必须给出相应的局部贡献规律。标量场、相对于参考体积的物理密度、相对于坐标体积的形式/密度系数，必须明确区分。

形式使用带符号的雅可比行列式；无向密度使用绝对值。度规可以提供长度和体积，但一般形式的拉回与积分不要求预先给定度规。标准坐标体积的规范化、线性、可加性与连续性解释定义与通常积分的一致性；不声称仅凭协变性唯一决定全部积分理论。

## 交互实验与验证

五类实验使用可独立测试的纯数值模型和响应式 SVG。控制项改变局部数据，文字解释同时展示局部读数、分段累计或精确总量，避免把它们混为同一种对象。

- 换元：比较形式、质量与仅按参数累计标量；显示精确值及中点和误差。
- 有向面积：剪切不改行列式，交换向量反号，退化时为零。
- 线性测量：允许零形式，等值线绘制不除以单个可能为零的系数。
- 曲线：局部求值等于累计积分的导数，反向路径总积分反号。
- 图卡分工：权重逐点相加为一，改变分工不改变总量；玩具例子不冒充完整的单位分解存在性证明。

校验运行 `npm test` 与 `npm run build`。DOM 校验覆盖阅读模式、旧锚点、深层定义跳转、复习链接、输入重置及清理；视觉验收另需桌面和手机浏览器。随文实验必须在切课时解除事件监听，专题实验和知识图谱必须取消动画和 resize 监听。

## 延伸阅读

以下作者讲义供进一步研读；本项目的小算例与交互代码独立编写。

- [Reyer Sjamaar：Manifolds and Differential Forms](https://pi.math.cornell.edu/~sjamaar/manifolds/)：本科层次的流形与形式课程，明确要求线性代数和多元微积分，说明为什么需要前置桥梁。
- [David Tong：Electromagnetism](https://davidtong.org/teaching/electromagnetism/)：从向量分析、电势和 Maxwell 方程到协变电磁学的完整本科路线。
- [David Tong：The Formalism of Quantum Mechanics](https://davidtong.org/pdfs/teaching/quantum-mechanics/qm3.pdf)：内积、算符、测量与有限维态空间的进一步说明。
